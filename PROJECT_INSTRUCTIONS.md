# Project instructions

This repository is the system of record for the research. Maintain: detailed research plan, phase-separated branches, step-by-step status log, error log, reproducible scripts, data manifests/checksums, README status, and final manuscript.

Research should search broadly for market data where applicable, account for transaction costs/slippage/brokerage, avoid look-ahead bias, stop after the proposed phases, and conclude with results, limitations, and future research directions.

Large source datasets should not be copied wholesale into Git history when impractical; retain manifests/checksums and derived research artifacts that allow reproducibility.

Conversation records should capture user-visible requests and material research decisions/updates. Hidden chain-of-thought is not stored; instead, methodological decisions are logged transparently.
